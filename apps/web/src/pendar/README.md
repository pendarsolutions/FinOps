# Pendar design system

Generated by scripts/pull-pendar.sh from Specimen (Pendar v3). Don't edit: change it in Specimen and pull again.

- `tokens.css`: colours, type, spacing, radii, shadows and motion, light and dark.
- `fonts/`: Estedad, under the SIL Open Font License 1.1 (`OFL.txt`).
- `icons.svg`, `icons.ts`: the icon sprite, and which icons mirror in left-to-right text.
- `logo.ts`: the wordmarks and the symbol as paths, and the order the animated logo lays its bricks.
