FinOps agent 0.3.0 makes an installation something a team can run on its own: nightly backups with one-command
restore, password recovery, and member management. The interface now follows the Pendar design system, with Solar
Hijri dates and a fully Persian report.

![Overview](https://raw.githubusercontent.com/{{REPO}}/v{{VERSION}}/docs/images/overview.png)

## What's new

- **Backups, on by default.** Every night at 03:30, kept for 14 days, in `/var/backups/finops-agent`. To back up
  now, or to restore, use one command:

  ```bash
  sudo /opt/finops-agent/backup.sh
  sudo /opt/finops-agent/backup.sh --restore FILE
  ```

  A restore asks first and backs up the current data before changing anything. To move to a new server, install
  there and restore a backup. Copy backups off the server too.
- **Getting back in.** With email set up, the sign-in page sends a one-time reset link. Without email, an admin sets
  a temporary password under Settings, and a server command covers a locked-out owner.
- **Members.** Change a member's role or remove them under Settings. Removing someone ends their access at once.
- **Pendar design.** The interface uses Pendar's colours, the Estedad font, its icons and its wordmark. Dark mode
  follows your system. Motion follows Pendar's guideline and stays still when reduced motion is on.
- **Solar Hijri dates** throughout the Persian interface, and a **Persian report** with Persian headers, digits and
  dates.

## Fixed

- `sudo ./install.sh` failed with "Permission denied" on a fresh clone.
- A password change didn't end sessions that were already signed in.

## Install

On a server with internet access:

```bash
git clone https://github.com/{{REPO}}.git && cd "$(basename {{REPO}})"
git checkout v{{VERSION}}
sudo ./install.sh --domain finops.example.ir
```

If Docker Hub or GitHub's registry isn't reachable from the server, use the offline bundle attached below:

```bash
curl -LO https://github.com/{{REPO}}/releases/download/v{{VERSION}}/finops-agent-{{VERSION}}.tar.gz
curl -LO https://github.com/{{REPO}}/releases/download/v{{VERSION}}/SHA256SUMS
sha256sum -c SHA256SUMS
tar xzf finops-agent-{{VERSION}}.tar.gz && cd finops-agent-{{VERSION}}
sudo ./install.sh --bundle images.tar.gz
```

## Upgrading from 0.2.0

Run the 0.3.0 installer the same way. Your settings and data are kept, the database is upgraded when the app
starts, and the nightly backup is set up. To get password-reset emails, add your SMTP settings to
`/opt/finops-agent/.env` (see [installation](https://github.com/{{REPO}}/blob/v{{VERSION}}/docs/installation.md#alerts)).

The full list of changes is in the [changelog](https://github.com/{{REPO}}/blob/v{{VERSION}}/CHANGELOG.md).
