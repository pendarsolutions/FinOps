FinOps agent 0.3.0 makes an installation something a team can run on its own: a one-line install, the
`finops-agent` command for everything after it, nightly backups with one-command restore, password recovery, and
member management. The interface now follows the Pendar design system, with Solar
Hijri dates and a fully Persian report.

![Overview](https://raw.githubusercontent.com/{{REPO}}/v{{VERSION}}/docs/images/overview.png)

## What's new

- **One-line install.** No clone needed:

  ```bash
  curl -fsSL https://github.com/{{REPO}}/releases/latest/download/install.sh | sudo bash
  ```

  It asks a few questions in a terminal, or takes them as options (`--domain`, `--set KEY=VALUE`, `--yes`) in scripts.
- **The `finops-agent` command** runs the installation from the command line:

  ```bash
  sudo finops-agent status
  sudo finops-agent config set SMTP_HOST=mail.example.ir ALERT_EMAIL_TO=ops@example.ir
  sudo finops-agent upgrade
  sudo finops-agent doctor
  ```

  Also `address` (including running behind your own reverse proxy), `logs`, `restart`, `backup`, `restore`,
  `reset-password`, `test-alerts` and `uninstall`.
- **The dashboard only.** An installation no longer serves a landing page: visitors get sign-in, and a fresh
  installation opens on creating the first account.
- **Backups, on by default.** Every night at 03:30, kept for 14 days, in `/var/backups/finops-agent`.
  `sudo finops-agent backup` backs up now and `sudo finops-agent restore FILE` puts one back. A restore asks first
  and backs up the current data before changing anything. To move to a new server, install there and restore a
  backup. Copy backups off the server too.
- **Getting back in.** With email set up, the sign-in page sends a one-time reset link. Without email, an admin sets
  a temporary password under Settings, and `sudo finops-agent reset-password` covers a locked-out owner.
- **Members.** Change a member's role or remove them under Settings. Removing someone ends their access at once.
- **Pendar design.** The interface uses Pendar's colours, the Estedad font, its icons and its wordmark. Dark mode
  follows your system. Motion follows Pendar's guideline and stays still when reduced motion is on.
- **Solar Hijri dates** throughout the Persian interface, and a **Persian report** with Persian headers, digits and
  dates.

## Fixed

- Running the 0.2.0 installer again without `--domain` switched a domain installation to its IP address.
- `sudo ./install.sh` failed with "Permission denied" on a fresh clone.
- A password change didn't end sessions that were already signed in.

## Install

```bash
curl -fsSL https://github.com/{{REPO}}/releases/download/v{{VERSION}}/install.sh | sudo bash
```

If Docker Hub or GitHub's registry isn't reachable from the server, use the offline bundle attached below:

```bash
curl -LO https://github.com/{{REPO}}/releases/download/v{{VERSION}}/finops-agent-{{VERSION}}.tar.gz
curl -LO https://github.com/{{REPO}}/releases/download/v{{VERSION}}/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
tar xzf finops-agent-{{VERSION}}.tar.gz && cd finops-agent-{{VERSION}}
sudo ./install.sh --bundle images.tar.gz
```

## Upgrading from 0.2.0

Run the 0.3.0 installer once, as above. It keeps your settings, data and domain, upgrades the database when the app
starts, sets up the nightly backup and installs the `finops-agent` command. Later versions upgrade with
`sudo finops-agent upgrade`. To get password-reset emails, set up email
([installation guide](https://github.com/{{REPO}}/blob/v{{VERSION}}/docs/installation.md#alerts)).

The full list of changes is in the [changelog](https://github.com/{{REPO}}/blob/v{{VERSION}}/CHANGELOG.md).
