FinOps agent is open-source cost management for startups and small teams that run on Iranian cloud and VPS
providers. Install it on one server, add your other servers from the dashboard, and see what each one costs, what it
actually uses, and where you can pay less. This is the first public release.

![Overview](https://raw.githubusercontent.com/{{REPO}}/v{{VERSION}}/docs/images/overview.png)

## What it does

- **Prices your servers exactly** from each provider's official price page, using exact decimal arithmetic. Every
  line links to its source and shows when the price was read.
- **Covers seven Iranian providers:** Liara, ArvanCloud, ParsPack, Server.ir, IranServer, MobinHost and Chabokan.
  Six are updated automatically twice a day. ArvanCloud is updated from reviewed price files.
- **Reads real usage** over SSH with a key that can run only one read-only script.
- **Suggests savings**, such as a cheaper equivalent plan, billing a test server by the hour, or a smaller plan
  once 14 days of usage have been measured. Each suggestion shows what changes, what to ask the provider before
  moving, the risk and effort, and when a move pays off.
- **Alerts you** by email or Bale when prices change, an update fails, or a renewal is close.
- Persian and English interface, with Toman, Rial and Jalali dates. The optional AI features are off by default and
  never calculate a number.

## How accurate it is

- Totals are calculated by tested code, not estimated. ParsPack's formula reproduces the total shown by its own
  calculator, and scraped prices match the providers' pages exactly.
- When a price isn't published, the app says **price unavailable** instead of guessing, and every assumption is
  written next to the quote.
- These are public list prices. Discounts, negotiated rates and fees that aren't on the price page are not included.
  If a number doesn't match your invoice, please [report it](https://github.com/{{REPO}}/issues/new?template=wrong-price.md).

## Install

On a server with internet access:

```bash
git clone https://github.com/{{REPO}}.git && cd "$(basename {{REPO}})"
git checkout v{{VERSION}}
sudo ./install.sh --domain finops.example.ir
```

If Docker Hub or GitHub's registry isn't reachable from the server, use the offline bundle attached below. It holds
every image the app needs:

```bash
curl -LO https://github.com/{{REPO}}/releases/download/v{{VERSION}}/finops-agent-{{VERSION}}.tar.gz
curl -LO https://github.com/{{REPO}}/releases/download/v{{VERSION}}/SHA256SUMS
sha256sum -c SHA256SUMS
tar xzf finops-agent-{{VERSION}}.tar.gz && cd finops-agent-{{VERSION}}
sudo ./install.sh --bundle images.tar.gz
```

The installer is safe on a server that already runs other things. To upgrade later, run the new version's installer
the same way. Settings and data are kept.

## Known limitations

The [changelog](https://github.com/{{REPO}}/blob/v{{VERSION}}/CHANGELOG.md#known-limitations) lists them. The main
ones: list prices only, no warning yet when a provider changes a plan's specs under the same name, and ArvanCloud
prices are updated by hand.
